# Śviętovit PWA v8: jak v7 + obsługa aplikacji na Androida (głos, przycisk wstecz)

1. W repozytorium GitHub zachowaj `.github/workflows/pages.yml` i plik `docs/.nojekyll`.
2. Podmień zawartość folderu `docs` zawartością `docs` z tego zipa (Add file → Upload files, z usunięciem starych plików).
3. Poczekaj na zakończenie workflow „Deploy” w zakładce Actions, potem odśwież stronę (na telefonie zamknij i otwórz aplikację, żeby zaktualizował się cache).

Nowe kursy (PL): nowogrecki, niemiecki, francuski, włoski, hiszpański, rosyjski, turecki, staronordycki, estoński, serbski, fiński. Treść wymaga sprawdzenia przez native speakerów. Wersja angielska nowych kursów jeszcze nie istnieje (interfejs w EN pokaże polską treść).
