# Śviętovit jako aplikacja webowa (PWA)

Działa w Chrome na każdym Androidzie, bez APK. Wszystkie 10 kursów, lekcje, korony, XP, serie, serca, rozmowy, PL/EN, tryb offline.

## Jak to uruchomić (GitHub Pages)
1. Rozpakuj ten zip. W środku jest folder `docs`.
2. Wejdź do repozytorium na GitHubie (najlepiej nowego, publicznego), kliknij **Add file → Upload files**.
3. Przeciągnij **sam folder `docs`** (cały, razem z podfolderami) i kliknij **Commit changes**. Jeśli GitHub mówi o limicie, wgraj w dwóch partiach: najpierw `docs/pyodide`, potem resztę.
4. **Settings → Pages**: *Source* = *Deploy from a branch*, *Branch* = `main`, folder = `/docs`, **Save**.
5. Po ok. minucie strona jest pod adresem `https://TWOJA-NAZWA.github.io/NAZWA-REPO/`.
6. Otwórz ten adres w Chrome na telefonie, poczekaj aż się załaduje (pierwszy raz kilkanaście MB), potem menu ⋮ → **Dodaj do ekranu głównego** / **Zainstaluj aplikację**. Po tym działa też bez internetu.

Postęp zapisuje się w przeglądarce telefonu (osobno dla każdego kursu).
